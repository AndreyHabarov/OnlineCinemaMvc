# Исполнители и фотографии

В каждой из 36 демонстрационных карточек указаны пять реальных исполнителей.
Под описанием фильма показываются их фотографии и русские имена. Для
мультфильмов раздел обозначен как оригинальные голоса персонажей.

Составы проверены по разделам Cast / Voice cast источников, перечисленных
в `data/movie-casts.json`. Среди пяти исполнителей есть основные и
дополнительные роли; это не полный список титров фильма.

## Локальные данные

- `data/movie-casts.json` связывает фильм с пятью исполнителями.
- `data/actor-photo-sources.json` содержит русское имя, путь фотографии,
  страницу Wikimedia Commons, автора и лицензию каждого файла.
- `OnlineCinema.Mvc/wwwroot/images/actors/` содержит локальные портреты.

Фотографии имеют свободные лицензии Creative Commons либо статус public
domain. Источники и авторы доступны в раскрываемом блоке под карточками.
Использованы фотографии разных лет; кадрирование в интерфейсе не изменяет
сохранённые файлы. Внешние страницы нужны только для просмотра атрибуции,
сами портреты загружаются с сайта и доступны без CDN.

Каталог составов загружается и проверяется один раз при старте. Страницы
используют данные из памяти; дополнительных запросов к внешним сайтам нет.
Схема PostgreSQL не меняется: поле Actor хранит список имён, фотографии и
источники являются воспроизводимыми справочными данными проекта.

## Обновление существующей базы

Docker-инициализатор обновляет только известные прежние демосписки актёров.
Для локальной разработки после загрузки каталога:

```powershell
./scripts/Update-DemoCast.ps1
```

Создаётся проверенный приватный backup. Служебный ключ `cast:v1:<slug>`
делает преобразование однократным. Пользовательский состав не перезаписывается;
если он отличается от справочного, карточка сохраняет его текст и не
показывает неподходящие фотографии. Остальные поля фильма, пользователи,
заказы и билеты не изменяются. Новые фильмы сразу получают пять имён.
