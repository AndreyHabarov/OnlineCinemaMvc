# Структура проекта

- `OnlineCinema.Domain`: сущности Identity/кинотеатра, DbContext, ограничения и миграции EF Core.
- `OnlineCinema.Application`: прикладная команда покупки, проверка доступности/возраста/цены,
  транзакция выдачи билетов, обработка повторов и конфликтов, московские часы кинотеатра.
- `OnlineCinema.Mvc`: HTTP-контракты и валидация форм, авторизация, контроллеры, SQL-проекции
  страниц, Razor и JavaScript, хранение загруженных изображений.

MVC зависит от Application и Domain; Application зависит от Domain, но не от MVC.
Application подключается через `AddOnlineCinemaApplication`. Команда `PurchaseRequest`
не содержит типов HTTP и дополнительно проверяется прикладным сервисом.

DbContext пока находится в Domain: это существующая структура приложения.
Отдельные repository/unit of work поверх EF не добавлены: DbContext уже выполняет
эти функции. Чтение страниц остаётся рядом с их проекциями; выделять дополнительные
слои следует при появлении реального повторного использования или сложности.
