# Исправления админки

Администратор с ролью `admin` управляет жанрами и акциями через `/Admin/Genres`
и `/Admin/Promotions`. В формах ошибки остаются видимыми; окно закрывается
только после успешного сохранения. Поиск передаётся серверу, страницы имеют
стабильную сортировку, размер страницы ограничен 1–100 записями.

Жанры уникальны без учёта регистра и пробелов по краям. Связанный с фильмами
жанр нельзя удалить: проверка действует и в PostgreSQL. Адреса акций также
уникальны. Миграция сохраняет первый старый адрес `NewDiscount`, а дубликатам
добавляет суффикс с ID (`NewDiscount-6`, `NewDiscount-7`). Записи и изображения
этих акций сохраняются.

Сохранение акции использует multipart/form-data. При создании изображение
обязательно; при редактировании без файла старое изображение сохраняется.
Допускаются JPEG, PNG и WebP до 2 МБ, с проверкой расширения и сигнатуры.
SVG и произвольные файлы не принимаются. Имя файла генерирует сервер.
Новый файл сохраняется до изменения записи; при ошибке БД он удаляется.
После успешной замены удаляются только ранее загруженные управляемые файлы,
на которые больше не ссылаются акции. Изображения из исходников не удаляются.
Папка `wwwroot/images/promotion/uploads/` исключена из Git; её нужно сохранять
вместе с базой при переносе приложения.

Публичные списки могут быть пустыми. Ошибки БД больше не маскируются под 404.
Данные в таблицах выводятся как текст, без вставки названий в HTML-атрибуты.

## Проверка

При запущенном локальном сайте и БД этого Docker Compose:

```powershell
./scripts/Test-Admin.ps1
```

Скрипт создаёт собственные временные записи и проверочного администратора,
проверяет CRUD, дубли, связи, поиск, параметры страницы, multipart, запрещённые
ссылки и замену изображений. В конце удаляет только созданные им данные.
