# Frontend: «Графит и малина»

## Палитра и CSS

`theme.css` содержит общие токены `--cinema-*`: фон, поверхности, текст,
акцент, границы, радиусы и переходы. `site.css` отвечает за страницы и общие
компоненты; `booking.css` — за места, билеты и печать; `error.css` — за
самостоятельную страницу ошибок. Внешние библиотеки не редактируются.

Основной фон — #141218, поверхность — #24202A, акцент — #BD257F,
светлый акцент — #F58AC6. Цвет и цена места не меняют серверный расчёт заказа.
Состояния места различаются цветом, рамкой, доступностью и aria-pressed.

## Нейминг

- CSS-классы и DOM-id: kebab-case, например `movie-card`, `purchase-form`.
- CSS-переменные: `--cinema-*`, например `--cinema-accent`.
- Состояния собственных компонентов: `is-selected`, `is-occupied`.
  Состояния Bootstrap/DataTables сохраняют их стандартные имена.
- JS-переменные и функции: camelCase, содержательные названия:
  `checkoutElement`, `selectedSeats`, `isPurchasePending`, `updateSelectionSummary`.
- Имена JS-файлов: нижний регистр, например `movie.js`, `checkout.js`, `receipt.js`.
- Связи JS/Razor: DOM-id, `data-seat-id`, `data-hall-id`, `data-date`.
  При переименовании обновлять шаблон и обработчик вместе.
- HTTP-поля и `name` серверных форм сохраняют согласованный контракт сервера.

Стили подключаются с asp-append-version. Переименование только регистра файла
фиксировать через промежуточное имя в Git: Linux различает регистр.

## Проверка пользователем

```powershell
./scripts/Start-Demo.ps1
```

Откройте http://localhost:8080 (либо APP_PORT из .env). Если браузер показывает
прежний экран, выполните Ctrl+F5. Проверьте афишу, Детям/Арт, акции, новости,
залы, регистрацию/вход и покупку: постер → дата → сеанс → места → билет.
Повторите на узком экране, проверьте кабинет и печать билета. В админке
проверьте формы, поиск и пагинацию под аккаунтом с ролью admin.

Схема зала и админская таблица прокручиваются внутри своих контейнеров.
Навигация и формы перестраиваются для мобильного экрана. Движение карточек
отключается при prefers-reduced-motion.
