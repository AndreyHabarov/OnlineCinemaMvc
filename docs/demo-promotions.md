# Акции и подборки

В новой демонстрации есть три предложения с отдельными карточками и
страницами: «Вечер культового кино», «Кино всей семьёй», «Ваш зал — ваш вечер».
Изображение и название открывают подробности, кнопка ведёт к подборке
фантастики, семейным фильмам или сравнению залов.

Это информационные демопредложения. Билет оформляется по обычной цене
сеанса и выбранных мест; денежные скидки и Пушкинская карта не подключены.
Старые шаблоны с обещаниями иных цен заменяются только при точном совпадении
известных значений. Произвольные пользовательские записи сохраняются.

## Данные и обновление

Источник — `data/demo-promotions.json`. Стабильные ключи связывают предложения
с ID, ссылка на жанр вычисляется по его служебному ключу, а не фиксированному
ID другой базы. Обновление оформления v2 однократное, не восстанавливает
удаления и не перезаписывает частично изменённые пользователем шаблоны.
Старые адреса NewDiscount / NewDiscount-6 / NewDiscount-7 перенаправляют
на обновлённую запись, если она сохранилась.

Docker загружает данные автоматически. Для существующей локальной БД:

```powershell
./scripts/Update-DemoPromotions.ps1
```

Перед изменениями создаётся проверенный приватный backup. Пользователи,
фильмы, места, сеансы, заказы и билеты не изменяются.

## Иллюстрации

Созданы встроенным ImageGen и сохранены в
`OnlineCinema.Mvc/wwwroot/images/promotion/`:

| Файл | Задание |
| --- | --- |
| cult-night-v2.png | Киноплёнка, VHS и хлопушка; графит, малиновые блики, свет проектора |
| family-cinema-v2.png | Попкорн, бумажные звёзды, игрушки и билеты; тёплая семейная атмосфера |
| choose-hall-v2.png | Пустой уютный кинозал с малиновыми креслами и мягким светом |

Все изображения — концептуальные иллюстрации без людей, надписей и логотипов,
в формате 16:9. Исходное задание каждого файла сохранено в
`data/promotion-image-prompts.json`; используется встроенный инструмент,
вызов CLI/API с личным ключом не применялся.
