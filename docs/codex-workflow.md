# Работа с Codex в OnlineCinema

Общие правила проекта находятся в `AGENTS.md`. Codex читает их при работе в репозитории. Они описывают границы изменений, запуск, проверки, сохранность данных и порядок commit/push.

## Три скилла

Скилл — инструкция для повторяющегося вида работы. Он подключается к основному агенту и сам по себе не запускает отдельного исполнителя.

| Скилл | Когда использовать |
| --- | --- |
| `onlinecinema-delivery` | Завершить исправление: проверить результат, обновить локальный бэклог, сделать согласованные commit/push. |
| `onlinecinema-database` | Изменить миграции, подключение PostgreSQL или повторяемые демоданные с сохранением существующих записей. |
| `onlinecinema-user-flows` | Проверить путь пользователя в браузере: от каталога и авторизации до выбора места и получения билета. |

Примеры сообщений Codex:

```text
Используй $onlinecinema-delivery и выполни следующую задачу из backlog.md.
Используй $onlinecinema-database: проверь повторный запуск сидирования без дублей и потери заказов.
Используй $onlinecinema-user-flows: проверь покупку билета начиная с нажатия на постер.
```

Скиллы установлены в личной папке `~/.codex/skills/`, каждый в своей подпапке с `SKILL.md` и `agents/openai.yaml`. Они доступны на этом компьютере и не входят в Git проекта. Для другого компьютера нужно отдельно перенести эти три папки в личную папку скиллов Codex. Если новые скиллы не появляются в списке, перезапустите Codex.

## Субагент для проверки

Проектный профиль находится в `.codex/agents/onlinecinema-reviewer.toml` и входит в Git. Субагент получает отдельную задачу, проверяет код и возвращает отчёт основному агенту. Он настроен на чтение: не исправляет файлы, не запускает миграции, не изменяет БД и не делает commit/push. Модель наследуется от основного агента.

Примеры сообщений:

```text
Запусти субагента onlinecinema-reviewer для проверки незакоммиченных изменений покупки билетов.
Запусти субагента onlinecinema-reviewer для проверки последнего коммита. Верни конкретные ошибки с путями и строками.
```

Указывайте область проверки: незакоммиченные изменения, конкретный коммит или диапазон. Основной агент рассматривает замечания, исправляет подтверждённые ошибки и выполняет нужные проверки. По правилам `AGENTS.md` независимая проверка также нужна перед коммитом изменений авторизации, покупки или миграций.

Профиль не является постоянно работающим процессом. Он используется при запуске субагента. Если текущее окружение не поддерживает выбор именованного профиля, основной агент должен сообщить об этом и передать инструкции профиля обычному субагенту при разрешённой делегации.

Форматы проверены при создании; автоматическое обнаружение профиля текущим интерфейсом Codex отдельно не подтверждено. При необходимости откройте проект в новой сессии Codex.

## Обновление правил

Можно написать Codex:

```text
Обнови AGENTS.md с учётом текущего состояния проекта и наших договорённостей. Не меняй README и не добавляй backlog.md в Git.
```

Сам файл — обычный Markdown. Его можно редактировать вручную; специальная команда для обновления существующего файла не требуется.
