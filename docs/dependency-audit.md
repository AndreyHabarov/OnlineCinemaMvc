# Проверка зависимостей

В октябре 2026 года из приложения удалён AutoMapper 13.0.1, затронутый [GHSA-rvv3-g6hj-g44x](https://github.com/advisories/GHSA-rvv3-g6hj-g44x). Для небольшого набора моделей используются явные SQL-проекции `Mapping/ViewProjections.cs`. Переход на AutoMapper 15+ потребовал бы отдельной лицензии по [инструкции библиотеки](https://docs.automapper.io/en/latest/15.0-Upgrade-Guide.html).

Также удалён неиспользуемый `Microsoft.VisualStudio.Web.CodeGeneration.Design`: он подключал уязвимые версии Microsoft.Build, NuGet.Packaging, NuGet.Protocol и System.Text.Json. Генератор MVC-кода не используется при запуске приложения. EF Core Design и локальный dotnet-ef сохранены для миграций.

Проверка прямых и транзитивных NuGet-пакетов:

```powershell
dotnet restore OnlineCinemaMvc.sln
dotnet list OnlineCinemaMvc.sln package --vulnerable --include-transitive --no-restore
```

Каталог уязвимостей требует доступа к NuGet. Успешный restore и доступный каталог — обязательные условия: результат после неудавшегося восстановления не подтверждает безопасность. Отсутствие известных уязвимостей на дату проверки не гарантирует отсутствие ошибок или будущих предупреждений. Клиентские ресурсы LibMan проверяются отдельно.

После изменения пакетов проверять сборку, затронутые страницы и интеграционные сценарии. Подробности хранятся в локальном бэклоге, который не включается в Git.

Секреты удалены из текущих отслеживаемых настроек; пароль новой контейнерной БД генерируется локально. Старые значения могут оставаться в истории Git. Не считать удаление строки ротацией пароля: старые активные учётные данные нужно заменить в соответствующем сервисе. Очистка истории требует отдельного согласования и не выполнялась.
