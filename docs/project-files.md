# Файлы проекта и Git

Готовые клиентские библиотеки в `OnlineCinema.Mvc/wwwroot/lib` хранятся в Git:
после клонирования сайт может работать без скачивания файлов с CDN.
`OnlineCinema.Mvc/libman.json` перечисляет только используемые JS, CSS,
шрифты и карты исходников. Полные исходники, отдельные модули, SCSS,
локализации и дополнительные сборки библиотек здесь не нужны.
Существующие файлы лицензий сохранены.

Поле `files` ограничивает восстановление конкретными файлами:
[справочник LibMan](https://github.com/aspnet/LibraryManager/wiki/libman.json-reference).
При обновлении версии библиотеки проверяйте diff готовых файлов и сценарии
сайта; форматирование сторонних библиотек отключено в `.editorconfig`.
Изменения сгенерированных комментариев минификатора не следует смешивать
с исправлениями приложения.

`.editorconfig` задаёт UTF-8, LF и перевод строки в конце исходников.
`.gitattributes` закрепляет LF для текстовых файлов и бинарный режим для
изображений и шрифтов. Настройки IDE, сборки, пароли, дампы и локальный
`backlog.md` исключены через `.gitignore`.

Перед удалением изображений проверяйте ссылки и в исходниках, и в БД.
Исходные картинки скрытых фильмов сохраняются, пока записи БД их используют.
Приватные копии перед очисткой находятся в игнорируемом `backups/`.
