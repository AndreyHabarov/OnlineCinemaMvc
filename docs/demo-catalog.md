# Демонстрационный каталог американского кино 90-х

В `data/demo-movies.json` находятся 12 фильмов 1990–1999 годов с русскими
названиями, авторскими описаниями, именами режиссёров и актёров, жанрами и длительностью.
«Матрица» — совместное производство США и Австралии; остальные фильмы указаны как США.
Дата `ReleaseDate` означает первоначальный выход в американский кинопрокат.
Для существующей схемы она записывается в `PremiereDate` и `WorldPremiere`;
это не дата первого российского проката или фестивальной премьеры.
Возрастные значения предназначены для демонстрационных фильтров сайта.
Рейтинг не заполняется вымышленными оценками.

## Загрузка

В готовой [демонстрации Docker](quick-start.md) каталог, залы, места, новости,
акции и расписание загружаются автоматически. Сидирование сохраняет изменения
и удаления, не затрагивает пользователей и билеты. Следующий ручной скрипт
предназначен для локальной разработки и обновляет каталог намеренно.

После подготовки PostgreSQL по `docs/local-development.md`, из корня проекта
в PowerShell 7 выполните:

```powershell
./scripts/Update-DemoCatalog.ps1
```

Скрипт работает только с сервисом `db` текущего Docker Compose.
Перед обновлением он сохраняет приватный дамп в исключённой из Git папке `backups/`.
Каталог загружается одной транзакцией; повторный запуск обновляет существующие
фильмы по оригинальному названию, не создавая новые копии.
Файлы постеров проверяются перед изменениями.

Предыдущие фильмы становятся невидимыми, но остаются в базе со своими связями.
Их изображения сохраняются: старые записи продолжают ссылаться на эти файлы.
Пользователи, билеты и существующие сеансы не изменяются.
После загрузки каталога подготовьте [демонстрационное расписание](demo-schedule.md)
командой `./scripts/Update-DemoSchedule.ps1`.

## Постеры и источники данных

Оригинальные рекламные постеры сохранены локально в
`OnlineCinema.Mvc/wwwroot/images/movies/1990s/` и используются как на карточках,
так и на страницах фильмов. Источник каждого файла, URL изображения и дата
получения записаны в `data/movie-poster-sources.json`.
Постеры принадлежат правообладателям фильмов и не являются изображениями
со свободной лицензией; условия использования Википедией не означают отдельной
лицензии для этого проекта.
